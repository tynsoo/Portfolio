# Christeen Solis · Portfolio

Personal portfolio of Christeen Ann L. Solis: creative designer and aspiring front-end developer, BS IT (Cybersecurity) student at Mapúa Malayan Colleges Laguna.

Plain HTML, CSS and JavaScript in a single `index.html`, hosted on GitHub Pages.

## Editing
- Folders, works and certificates: the `FOLDERS`, `WORKS` and `CERTS` lists inside the `<script>` at the bottom of `index.html`.
- Text: search for ✏️ in `index.html`.
- Colors: the tokens at the top of the `<style>` block.
- Images live in `images/`.
